# 📝 Smart To-Do List App

A feature-rich To-Do List web application built using HTML, CSS, and JavaScript. The app helps users organize daily activities, manage tasks efficiently, and stay productive with built-in reminders and suggested healthy habits.

## 🚀 Features

* Add, edit, and delete tasks
* Mark tasks as completed
* Task completion statistics
* Duplicate task prevention
* Suggested productivity and wellness tasks
* Time-based reminders
* LocalStorage support for persistent data
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* LocalStorage API

## 📚 Key Learning Outcomes

* DOM Manipulation
* Event Handling
* Array Methods
* CRUD Operations
* Local Storage Management
* JavaScript Object Handling
* Responsive UI Design

## 🎯 Project Objective

To build a practical task management application that improves productivity while strengthening frontend development skills through real-world JavaScript implementation.
